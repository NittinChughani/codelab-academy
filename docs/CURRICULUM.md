## Practice tracks

The challenge library covers basics, conditionals, loops, numbers, bitwise operations, strings, arrays and more advanced algorithms. Each of the **69 problem types** has a C version and a C++ version with sample cases, a hint and a reference solution. Difficulty can be filtered (Easy / Medium / Hard).

Sample compilation checks only the **first** test case via a remote compiler. A sample pass is not a complete proof of correctness.

## Project progression

C: Calculator → Gradebook → Contact Book → Inventory Manager → Notes File Manager → Library Management System.

C++: Task List CLI → Bank Account Simulator → Digital Library → Terminal Quiz Engine → Expense Tracker → Text Adventure Engine.

Suggested method: read a lesson, predict the example output, run it, solve a related challenge, and finally build a mini-project.
