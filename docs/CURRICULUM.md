# Curriculum

## C language

| Lesson | Learning outcome |
| --- | --- |
| Your First C Program | Compile a minimal program and print output |
| Variables & Data Types | Declare and print typed values |
| If, Else & Decisions | Choose paths using comparisons |
| Loops in C | Write bounded repetition |
| Functions in C | Extract reusable logic |
| Arrays & Indexing | Iterate over fixed-size collections |

## C++

| Lesson | Learning outcome |
| --- | --- |
| Your First C++ Program | Use iostream for output |
| Input & Variables | Validate basic input |
| Loops in C++ | Write repeated operations |
| Vectors & Collections | Work with std::vector |
| Functions & References | Use read-only reference parameters |
| Classes & Objects | Encapsulate state with methods |

## Suggested future lessons

Pointers and memory safety, strings, structs, file I/O, debugging, C++ standard algorithms, inheritance, templates, and error handling.

## Teaching approach

Read the concept, run the example with a compiler, modify it to solve the challenge, and then take the quiz. The website does **not** execute user-submitted C or C++ code; learners run code in a local compiler or an external environment of their choice.
