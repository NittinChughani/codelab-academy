# Contributing to CodeLab Academy

Thank you for helping learners! We welcome corrections, additional lessons, quiz questions, translations, accessibility improvements, and bug fixes.

1. Check existing issues or open a new issue describing the improvement.
2. Fork the repository and create a focused branch.
3. Edit the relevant files. Keep examples accurate and beginner-friendly.
4. Run `node --check assets/data.js && node --check assets/app.js` if Node.js is available.
5. Manually test your changes in a browser and describe your tests in the pull request.
6. Open a pull request explaining what changed and why.

For lessons, include an original example, three key ideas, and a practical challenge. For quiz questions, provide four plausible options and an explanation. Avoid copying copyrighted teaching materials or large code examples from other sources.

Be respectful and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
